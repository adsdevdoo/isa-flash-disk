# 3D-модели

Модели копирует `tools/kicad/route_board.py` в `hardware/kicad/3d/`, футпринты ссылаются на `${KIPRJMOD}/3d/…`.
Источник всех моделей — библиотека KiCad 9.0.2 (`share/kicad/3dmodels`), лицензия CC-BY-SA 4.0 с исключением
KiCad для проектов. SHA-256 файлов — в `hardware/kicad/3d/SHA256SUMS`.

**PSOP-44.** В KiCad нет модели корпуса Intel PA28F008SA (корпус 13.30 × 28.20 мм, по концам выводов 16.00 мм,
[чертёж Intel](datasheets/intel-psop-44-package-2232-1.pdf)). Используется модель KiCad `PSOP-44_16.9x27.17mm`,
построенная под другой габарит: на рендере корпус может выглядеть шире и выводы — длиннее настоящих. Посадочное
место от этой модели не зависит и построено по чертежу Intel.

Рендеры показывают плату без перемычки на JP1 (так карта и поставляется) и без планки Keystone 9202.
