# Программирование флеш из DOS

Статус: **заготовка**. Полностью — на этапе 4.

## Правила, которые следуют из даташита

- Код записи и стирания выполняется из ОЗУ: пока флеш занята, она выдаёт регистр статуса вместо данных (DS с. 10).
- Перед записью блок стирается целиком (64 Кбайт); запись меняет только 1 → 0 (DS с. 16).
- После каждой записи или стирания — проверка SR.3, SR.4, SR.5; при ошибке — `50h` (DS с. 18–21).
- В конце — `FFh` и сверка данных чтением.
- Тайм-аут стирания блока — не меньше 10 с (DS с. 34).
- Порядок включения: `CTRL = WE_EN | VPP_EN`, пауза на установление VPP (tVPWH ≥ 100 нс, DS с. 33; на практике —
  время заряда конденсаторов цепи VPP, уточняется на прототипе), операции, `FFh`, `CTRL = 0`.

## Определение перемычки JP1 без порта чтения

Порта чтения на карте нет. Состояние JP1 определяем через саму флеш:

1. `CTRL = WE_EN | VPP_EN`.
2. Команда записи байта `40h` и данные `FFh` по любому адресу.
3. Дождаться SR.7 = 1, прочитать SR.3.
4. `50h`, `FFh`, `CTRL = 0`.

Если SR.3 = 1 — VPP нет, перемычка снята (DS с. 18). Если SR.3 = 0 — VPP есть.
Запись `FFh` не меняет ячейки: запись переводит биты только из 1 в 0, а у `FFh` все биты 1.
**Метод подтверждаем на прототипе**: даташит не описывает именно этот случай.
