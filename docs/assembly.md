# Сборка карты

Статус: **заготовка**. Полностью заполняется на этапе 5, когда будет плата.

Уже известно:

- Плата заказывается пустой и паяется вручную: логика SOIC, транзисторы SOT-23, пассивные 0805 с увеличенными
  площадками, переключатели, перемычка и резисторные сборки — выводные.
- Флеш PA28F008SA (PSOP-44) — снятые с модуля, после проверки по [original-module.md](original-module.md).
  На карту с 1 Мбайт ставится только U1, U2 не запаивается.
- Перемычка JP1 «WRITE» при сборке **не устанавливается** — карта выходит с аппаратной защитой от записи.
- Переключатели по умолчанию: окно CC000h, порты 2A0h ([memory-map.md](memory-map.md)).
- В IBM 5160 карту не ставить в слот J8 ([isa-interface.md](isa-interface.md)).
